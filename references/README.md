# References

What lives here:

- **`voice-samples/`** holds the raw, verbatim things you have actually sent (emails, posts, pages, DMs). `/onboard` saves your Q5 samples here. `context/voice-and-tone.md` is the distilled read of these. Keep them unedited. They are the ground truth for how you sound.
- **Docs you bring.** Any existing positioning, ICP sheets, decks, or teardowns you already had. Drop them here so `/onboard` can read them as raw input.
- **`{tool}-api.md`** is one guide per tool you wire in: its endpoints, auth flow, and the queries you run most. Research a tool once, save it here, and no future skill has to figure it out again.

Rule: interpreted facts and real artifacts only. This is not a dumping ground for raw exports. If it is old, move it to `archives/`. If it is a decision, log it in `intel/decisions/log.md`.
