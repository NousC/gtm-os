# Views

One file per belief or number you want to watch change over time. Examples: `icp-thesis.md`, `pricing-view.md`, `positioning-bet.md`, `north-star-metric.md`.

Each file is append-only with the newest entry on top, every entry dated. The point is to scroll the file and see how your thinking moved, and why. This is different from `intel/decisions/log.md`: a decision is a choice you made on a day, a view is the understanding that kept shifting underneath those choices.

Use it when you catch yourself thinking "wait, didn't I see this differently a month ago?" That question is exactly what this folder answers.

## Format

```
# ICP thesis

## 2026-06-26
We now think the buyer is the GTM engineer, not the founder. Three calls this week
where the founder forwarded us straight to the person who actually owns the stack.

## 2026-06-01
Leaning founder-led. They reply fastest. Open question whether they are the real buyer.

## 2026-05-15
Original guess: RevOps leads. No evidence yet, just the obvious answer.
```

Newest on top so the current view is the first thing you read, and the history is right below it.
